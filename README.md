# სპორტული შედეგების და მატჩების ანალიტიკოსი AI აგენტი (Sports Analytics Agent)

ეს არის დიდ ენის მოდელზე (LLM) დაფუძნებული ავტონომიური ხელოვნური ინტელექტის აგენტი, რომელიც მომხმარებელს ეხმარება სპორტული მატჩების შედეგების, მებრძოლების/გუნდების სტატისტიკისა და მიმდინარე ფორმის სიღრმისეულ ანალიზში. 

სისტემა ეფუძნება ლოკალურ `transformers` არქიტექტურას (`Qwen/Qwen2.5-3B-Instruct`), რაც უზრუნველყოფს მაღალ სტაბილურობას გარე API-ებზე დამოკიდებულების გარეშე.

---

## 1. აგენტის აღწერა (PEAS)
* **Performance Measure (შესრულების საზომი):** მომხმარებლისთვის ზუსტი, დროული და სტრუქტურული სპორტული სტატისტიკისა და მატჩების (მაგ. UFC / MMA / ფეხბურთი) ანალიზის მიწოდება; ლოგიკურად სტრუქტურირებული პასუხის გენერირება.
* **Environment (გარემო):** სპორტული მონაცემების სივრცე, მებრძოლების/გუნდების სტატისტიკა, საბრძოლო სტილები და მომხმარებლის ტექსტური მოთხოვნები.
* **Actuators (აქტუატორები):** ტექსტური პასუხები, სპორტული შეჯამება, ტექნიკური ანალიზი და რეკომენდაციები ჩატში.
* **Sensors (სენსორები):** მომხმარებლის მიერ შემოყვანილი ტექსტური შეკითხვები (მაგ.: მებრძოლის დასახელება, სტილის ანალიზი, სტატისტიკური მოთხოვნა).

---

## 2. გარემოს თვისებები (7 ღერძი)
1. **სრულად თუ ნაწილობრივ დაკვირვებადი:** ნაწილობრივ დაკვირვებადი, რადგან აგენტს არ აქვს სრული წვდომა რეალურ დროში არსებულ ყველა ფარულ დეტალზე (მაგ. ბოლო წუთის ტრავმები, ფსიქოლოგიური მდგომარეობა ან გუნდის შიდა განწყობა).
2. **დეტერმინისტული თუ სტოქასტური:** სტოქასტური, ვინაიდან სპორტული მატჩებისა და ორთაბრძოლების შედეგები წინასწარ ბოლომდე პროგნოზირებადი არ არის.
3. **ეპიზოდური თუ თანმიმდევრული:** თანმიმდევრული, რადგან სპორტსმენის მიმდინარე ფორმა და ანალიზი დამოკიდებულია წინა ბრძოლების/ტურების შედეგებსა და კარიერულ დინამიკაზე.
4. **სტატიკური თუ დინამიური:** დინამიური, რადგან სპორტული მონაცემები, რეიტინგები და შედეგები მუდმივად იცვლება.
5. **დისკრეტული თუ განგრძობითი:** დისკრეტული, რადგან მომხმარებლის მოთხოვნები და მონაცემები გამოიხატება ცალკეული, მკაფიოდ გამოყოფილი ერთეულებითა და სტატისტიკური ციფრებით.
6. **ერთაგენტიანი თუ მრავალაგენტიანი:** ერთაგენტიანი, რადგან გადაწყვეტილებას იღებს და ანალიზს ატარებს ერთი ცენტრალური AI აგენტი.
7. **ცნობილი თუ უცნობი:** ცნობილი, ვინაიდან სპორტული წესები, სტატისტიკური მეტრიკები და მოდელის მუშაობის პრინციპი წინასწარ განსაზღვრულია.

---

## 3. აგენტის ტიპი
* **ტიპი:** Goal-based agent (მიზანზე დაფუძნებული აგენტი).
* **დასაბუთება:** აგენტის მთავარი მიზანია მომხმარებლის მოთხოვნის სრულყოფილად დაკმაყოფილება (კონკრეტული სპორტსმენის, მატჩის ან გუნდის სიღრმისეული ანალიზი). ამ მიზნის მისაღწევად ის ამუშავებს მონაცემებს, იყენებს ლოკალურ LLM არქიტექტურას და აგენერირებს დეტალურ, ლოგიკურ პასუხს.

## 4. პრობლემა და აუდიტორია
* **რა პრობლემას ჭრის:** ამცირებს სპორტული სტატისტიკისა და სპორტსმენების ბოლო შედეგების ხელით ძებნის დროს და აწვდის მომხმარებელს სტრუქტურირებულ, პროფესიონალურ ანალიზს ერთ სივრცეში (API შეზღუდვებისა და შეფერხებების გარეშე).
* **ვისთვის არის განკუთვნილი:** სპორტის მოყვარულებისთვის, UFC/MMA ფანებისთვის და ანალიტიკოსებისთვის.
