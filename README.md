# სპორტული შედეგების და მატჩების ანალიტიკოსი AI აგენტი (Sports Analytics Agent)

ეს არის დიდ ენის მოდელზე (LLM) დაფუძნებული ხელოვნური ინტელექტის აგენტი, რომელიც მომხმარებელს ეხმარება სპორტული მატჩების შედეგების, გუნდების სტატისტიკისა და მიმდინარე ფორმის ანალიზში.

## 1. აგენტის აღწერა (PEAS)
* **Performance Measure (შესრულების საზომი):** მომხმარებლისთვის ზუსტი, დროული და სტრუქტურული სპორტული სტატისტიკისა და მატჩების ანალიზის მიწოდება; შესაბამისი ხელსაწყოს (tool) სწორად არჩევა და გამოყენება.
* **Environment (გარემო):** სპორტული მონაცემების სივრცე, სატურნირო ცხრილები, მატჩების სტატისტიკა და მომხმარებლის ტექსტური მოთხოვნები.
* **Actuators (აქტუატორები):** ტექსტური პასუხები, გუნდების სტატისტიკური შეჯამება, მატჩების ანალიზი და რეკომენდაციები ჩატში.
* **Sensors (სენსორები):** მომხმარებლის მიერ შემოყვანილი ტექსტური შეკითხვები (მაგ.: გუნდის დასახელება, მატჩის შედეგები, სტატისტიკური მოთხოვნა).

## 2. გარემოს თვისებები (7 ღერძი)
1. **სრულად თუ ნაწილობრივ დაკვირვებადი:** ნაწილობრივ დაკვირვებადი, რადგან აგენტს არ აქვს სრული წვდომა რეალურ დროში არსებულ ყველა ფარულ დეტალზე (მაგ. ბოლო წუთის ტრავმები ან გუნდის შიდა განწყობა).
2. **დეტერმინისტული თუ სტოქასტური:** სტოქასტური, ვინაიდან სპორტული მატჩების შედეგები და მომავალი თამაშების გამოსავალი წინასწარ ბოლომდე პროგნოზირებადი არ არის.
3. **ეპიზოდური თუ თანმიმდევრული:** თანმიმდევრული, რადგან გუნდის მიმდინარე ფორმა და მატჩის ანალიზი დამოკიდებულია წინა ტურების შედეგებსა და სეზონის დინამიკაზე.
4. **სტატიკური თუ დინამიური:** დინამიური, რადგან სპორტული მონაცემები, სატურნირო მდგომარეობა და მატჩების შედეგები მუდმივად იცვლება.
5. **დისკრეტული თუ განგრძობითი:** დისკრეტული, რადგან მომხმარებლის მოთხოვნები და მატჩების მონაცემები გამოიხატება ცალკეული, მკაფიოდ გამოყოფილი ერთეულებითა და სტატისტიკური ციფრებით.
6. **ერთაგენტიანი თუ მრავალაგენტიანი:** ერთაგენტიანი, რადგან გადაწყვეტილებას იღებს და ანალიზს ატარებს ერთი ცენტრალური AI აგენტი.
7. **ცნობილი თუ უცნობი:** ცნობილი, ვინაიდან სპორტული წესები, სტატისტიკური მეტრიკები და ხელსაწყოების მუშაობის პრინციპი წინასწარ განსაზღვრულია.

## 3. აგენტის ტიპი
* **ტიპი:** Goal-based agent (მიზანზე დაფუძნებული აგენტი).
* **დასაბუთება:** აგენტის მთავარი მიზანია მომხმარებლის მოთხოვნის სრულყოფილად დაკმაყოფილება (კონკრეტული მატჩის ან გუნდის ანალიზი). ამ მიზნის მისაღწევად ის ირჩევს შესაბამის ხელსაწყოებს, ამუშავებს მონაცემებს და აგენერირებს ლოგიკურ პასუხს.

## 4. პრობლემა და აუდიტორია
* **რა პრობლემას ჭრის:** ამცირებს სპორტული სტატისტიკისა და გუნდების ბოლო შედეგების ხელით ძებნის დროს და აწვდის მომხმარებელს სტრუქტურირებულ ანალიზს ერთ სივრცეში.
* **ვისთვის არის განკუთვნილი:** სპორტის მოყვარულებისთვის, ფანებისთვის და ანალიტიკოსებისთვის.

## 5. ხელსაწყოები (Tools)
* `get_team_stats(team_name: str)` — იღებს გუნდის დასახელებას და აბრუნებს მის ბოლო შედეგებსა და სტატისტიკას.
